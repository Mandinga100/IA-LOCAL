# Template Canónico de Contenido — Asistente Integral 360

**Nota:** Proyecto actualmente sin blog implementado. Este template es para uso futuro.

---

## Estructura de Página de Contenido

```
# {Título H1: Mismo que meta title}

## Resumen
{Answer-first, <200 caracteres. Respuesta directa a la intención de búsqueda}

{Contexto, 2-3 párrafos}

## {H2: Tema principal}

{Contenido}

### {H3: Subtema}
{Contenido detallado}

### {H3: Subtema}
{Contenido detallado}

## {H2: Siguiente tema}

{Contenido}

---

## Preguntas Frecuentes

**¿Pregunta 1?**
Respuesta breve.

**¿Pregunta 2?**
Respuesta breve.

---

[Comienza gratis →](https://asistente360.com)
```

## Metadata Obligatoria

| Campo | Descripción |
|:------|:------------|
| `title` | Título H1, incluir keyword principal |
| `metaTitle` | Máx. 60 chars, pipe separador |
| `metaDescription` | Máx. 160 chars, keyword principal |
| `canonical` | URL canónica con trailing slash |
| `ogImage` | 1200x630, formato jpg/webp |
| `robots` | index, follow |

## Schema JSON-LD Recomendados

- **Article** — para blog posts
- **FAQPage** — para sección de preguntas frecuentes
- **SoftwareApplication** — para páginas de producto/feature

## Checklist de Contenido

- [ ] Answer-First en primer párrafo
- [ ] FAQ con schema
- [ ] Imagen con alt descriptivo
- [ ] Voz de marca: moderno, cercano, transparente
- [ ] Sin promesas financieras exageradas
- [ ] Enlaces internos a otras páginas del sitio
- [ ] CTA al final
