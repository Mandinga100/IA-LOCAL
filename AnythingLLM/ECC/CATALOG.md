## Maintenance

This file is the **single source of truth** for the ECC catalog taxonomy.

- **Update**: After adding/removing agents, skills, or commands, update the counts above and the taxonomy entries.
- **Validation**: Run `npm run catalog:check` to verify all documented counts match the filesystem.
- **Sync**: Run `npm run catalog:sync` to auto-update counts in README.md, AGENTS.md, SOUL.md, WORKING-CONTEXT.md, and translations.
- **Registry**: Run `npm run command-registry:generate` to regenerate `docs/COMMAND-REGISTRY.json` with the full dependency graph.
