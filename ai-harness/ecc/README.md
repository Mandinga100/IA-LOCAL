## 🎯 Propósito del Arnés Curado

Este directorio ha sido saneado quirúrgicamente para evitar sobrecargar a usuarios básicos y operadores de producción con tecnologías ajenas o herramientas que no se utilizarán. 

Conserva exclusivamente los componentes de alta fidelidad necesarios para:
1. **Documentación e Informes:** Word (`.docx`), PDF, ODT, RTF, Markdown y protocolo Zero-Chatter.
2. **Presentaciones Ejecutivas:** Estructuración de diapositivas PowerPoint (`.pptx`) y síntesis de alto impacto.
3. **Hojas de Cálculo y Finanzas:** Procesamiento de Excel (`.xlsx`), CSV y validación cuantitativa de tablas.
4. **Programación Ligera y Automatización:** Python 3.13, buenas prácticas de código, arquitectura y pruebas TDD (`pytest`).

## 📁 Inventario de Componentes Seleccionados

### 1. Agentes Especializados (`ECC/agents/`)
- `doc-updater.md`: Actualización, corrección de estilo y consistencia documental.
- `spec-miner.md`: Extracción de requisitos, especificaciones técnicas y síntesis estructurada.
- `code-reviewer.md`: Revisión de código, seguridad y cumplimiento de buenas prácticas.
- `silent-failure-hunter.md`: Detección preventiva de fallos silenciosos y excepciones no controladas.
- `planner.md`: Planificación metódica de tareas y workflows.
- `performance-optimizer.md`: Optimización de latencia, memoria y recursos de cómputo.
- `security-reviewer.md`: Auditoría de seguridad contra inyecciones y vulnerabilidades.
- `architect.md`: Diseño de arquitectura limpia y desacoplamiento de capas.

### 2. Skills Homologadas (`ECC/skills/`)
- `nutrient-document-processing`: Ingestión, formateo y extracción documental.
- `frontend-slides`: Generación y estructuración de diapositivas ejecutivas.
- `csv-analysis`: Análisis de datos tabulares, promedios, balances y métricas.
- `table-extraction`: Conversión de datos planos a tablas Markdown alineadas.
- `documentation-lookup`: Búsqueda y consulta de documentación técnica.
- `regex-vs-llm-structured-text`: Extracción híbrida determinista mediante expresiones regulares y LLM.
- `python-patterns`: Patrones de diseño modernos y buenas prácticas en Python.
- `python-testing`: Metodología y testing unitario exhaustivo.
- `tdd-workflow`: Flujo de trabajo de desarrollo guiado por pruebas.
- `error-handling`: Patrones de resiliencia y manejo seguro de errores.
- `verification-loop`: Bucle de verificación de calidad en 4 fases (Build, Visual, Pureza, Compilación).
- `security-review`: Seguridad en APIs y sanitización de entradas.
- `token-budget-advisor`: Asesoría de presupuesto de contexto para GPU de 4 GB y 24 GB.
- `docker-patterns`: Buenas prácticas de despliegue en contenedores Docker.

### 3. Reglas y Gobernanza (`ECC/rules/`)
- `common/`: Reglas generales de desarrollo limpio y documentación.
- `python/`: Estándares de tipado estricto (Type Hints) y calidad en Python.
- `security/`: Directivas de ciberseguridad, prevención de inyecciones y variables de entorno.

### 4. Configuración MCP (`ECC/mcp-configs/`)
- `mcp-servers.json`: Registro de herramientas MCP para AnythingLLM y agentes autónomos.
