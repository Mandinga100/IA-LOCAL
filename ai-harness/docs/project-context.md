# Contexto del Proyecto — Asistente Integral 360

## Visión General
**Asistente Integral 360** es una landing page moderna y una plataforma de gestión financiera personal impulsada por inteligencia artificial. El proyecto está construido con Next.js 15, TypeScript y Tailwind CSS, y se exporta como sitio estático a Firebase Hosting.

## Stack Tecnológico
- **Frontend:** Next.js 15 (App Router), React 18, TypeScript 5
- **Estilos:** Tailwind CSS 3.4, CSS Variables, modo oscuro nativo
- **UI:** shadcn/ui con primitivas Radix UI (35 componentes)
- **Gráficos:** Recharts (dashboard interactivo)
- **Formularios:** React Hook Form + Zod
- **IA:** Google Genkit + Gemini 2.0 Flash (pendiente de implementación)
- **Hosting:** Firebase Hosting (exportación estática a `out/`)
- **Base de datos:** Firebase Data Connect (pendiente de implementación)

## Propósito del Producto
Asistente Integral 360 es una aplicación financiera que ofrece:
1. **Gestión de Gastos Inteligente** — Clasificación y análisis automático de gastos
2. **Pagos Recurrentes Automatizados** — Control de suscripciones y débitos
3. **Asistente con IA** — Chatbot financiero inteligente
4. **Alertas Inteligentes** — Notificaciones predictivas de gastos
5. **Reportes Avanzados** — Dashboard con visualizaciones financieras
6. **Monitor de Precios** — Seguimiento de productos y servicios
7. **Listas de Compras Inteligentes** — Optimización del presupuesto familiar
8. **Gastos Comunes** — División y control de gastos compartidos

## Estado del Proyecto
- **Landing Page:** 100% funcional (10 rutas)
- **Dashboard interactivo:** Implementado con datos simulados
- **Formulario Early Access:** Validación Zod funcional, backend pendiente
